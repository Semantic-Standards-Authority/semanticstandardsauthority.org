1. Purpose
This Privacy Policy describes how the Semantic Standards Authority (SSA) collects, uses, and protects information in connection with its semantic standards, registries, and institutional publications.

2. Scope
This policy applies to all SSA digital assets, including:

SSA Registry (REG Index)

RA‑1 (Regulatory Antinomy Class)

SSA Runtime Admissibility Evaluation Model

SSA Suspension State Diagram

SSA GitHub repositories

SSA Zenodo publications

3. Data Collection
SSA collects only minimal data necessary for institutional operation:

Metadata of published standards and documents

Contributor identifiers (e.g., ORCID, institutional email)

Technical submission logs for version control and provenance tracking

SSA does not collect personal analytics, behavioral data, or profiling information.

4. Data Usage
Collected data are used exclusively for:

Maintaining semantic integrity of SSA standards

Ensuring provenance and authorship traceability

Supporting deterministic execution and semantic governance models

SSA does not sell, share, or transfer data to third parties.

5. Data Storage and Security
All data are stored in secure, access‑controlled environments:

GitHub repositories under SSA institutional ownership

Zenodo records under SSA DOI registration

Encrypted backups maintained within the UK jurisdiction

SSA applies deterministic access protocols and semantic validation before any data release.

6. Rights and Access
Contributors may:

Request correction of institutional metadata

Request removal of non‑essential identifiers

Obtain a copy of their institutional record upon written request

Requests should be sent to:
privacy@semanticstandardsauthority.org

7. Legal Basis
SSA operates under the UK Data Protection Act 2018 and GDPR principles.
All processing is based on legitimate institutional interest in maintaining semantic governance and publication integrity.

8. Updates
SSA may update this policy to reflect changes in governance or publication infrastructure.
Updated versions will be published at:
https://www.semanticstandardsauthority.org/privacy

🟥 10. GitHub Contributor Privacy Clause
SSA maintains public repositories on GitHub for version control, transparency, and institutional collaboration.
By contributing to SSA repositories, contributors acknowledge and consent to the following:

10.1 Public Attribution
Contributor names, GitHub usernames, and commit metadata are publicly visible as part of the repository’s version history.
SSA does not anonymize commit history, as it forms part of the institutional provenance chain.

10.2 Data Minimization
SSA does not collect or process any additional personal data beyond standard GitHub commit metadata (username, timestamp, commit message).

10.3 Institutional Use
Contributor metadata may be used solely for:

Authorship attribution in SSA publications

Semantic lineage tracking within SSA registries

Institutional audit and provenance validation

10.4 Third‑Party Platform Policy
GitHub operates independently under its own privacy policy.
Contributors should review GitHub’s privacy terms:
https://docs.github.com/en/site-policy/privacy-policies/github-privacy-statement (docs.github.com in Bing)

10.5 Removal Requests
Contributors may request removal of non‑essential identifying information from SSA documentation (not from GitHub commit history) by contacting:
privacy@semanticstandards.uk
